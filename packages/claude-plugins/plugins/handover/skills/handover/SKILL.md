# Handover

引き継ぎ文書を作成し、現在の会話内容を要約して、次の担当者が作業を継続できるようにします。この文書は ${user_config.HANDOVER_OUTPUT_PATH_FORMAT} に保存してください。

- 文書に「推奨スキル」セクションを追加し、エージェントが活用すべきスキルを提案してください。
- 他の成果物（仕様書、計画書、ADR、課題、コミット、差分など）に既に記録されている内容を重複して記述しないでください。代わりに、パスまたはURLで参照してください。
- APIキー、パスワード、個人を特定できる情報など、機密情報はすべて削除してください。

ユーザーが引数を渡した場合、それを次のセッションで重点的に取り組む内容の説明として扱い、それに応じてドキュメントを調整します。

フォーマット:
~~~md
---
claude_session_id: ${CLAUDE_SESSION_ID} # プリプロセッシングされた現セッションのID。このコメントを除いてそのまま転記すること。
---

# <タイトル>

...

## 推奨スキル
...

## 関連ファイル・リンク
...
~~~

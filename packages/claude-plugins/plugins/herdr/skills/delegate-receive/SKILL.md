# Herdr での委任を受ける

あなたは Herdr 経由で親エージェントから作業を委任された。

前提: `herdr` (本体) スキルと `herdr:gotcha` スキルをロードしておく。

## 親は割り込みで起きる

親はあなたの出力を監視していない。報告も質問も、親のペインへ直接送り、その割り込みで親を起こすこと。

送る文面は自由記述テキストなので、`herdr:gotcha` のタグ付きポインタで送る。本文は Write ツールで**あなた自身の**スクラッチパッドディレクトリ (システムプロンプトで指定されているもの。親のものとは別) へ書き出す:

```bash
herdr agent prompt <親の pane ID> "中間報告: <書き出したファイルの絶対パス>"
# もしくは: "質問: <...>" / "最終報告: <...>"
```

送ったら自分のターンを終える。親からの次の指示も割り込みとしてあなたのペインの入力行に着地するので、承認待ちや実行中のコマンドを抱えたまま終わらないこと。自分のペインは自分では閉じない (後始末は親がする)。

## 手順

1. $BRIEF_PATH を読む。タスク・完了の定義・作業ディレクトリ・親の pane ID・中間報告のタイミングを把握する。
2. タスクを実行する。
   - 依頼文書で指定されたタイミングで中間報告を送る。
   - 判断に迷ったら親に確認する。
3. 完了の定義を満たしたら最終報告を送る。

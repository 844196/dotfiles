# 動作確認用の一時ファイルを rm で片付けない

`rm` は confirmation (ask) の対象になっている。実害のない一時ファイルまでこまめに `rm` で片付けようとすると、その都度確認プロンプトが挟まり、auto mode で作業している意味が薄れる。これらのファイルは OS がいずれ回収するため、わざわざ消す必要がない。

動作確認や検証のためだけに作成した一時ファイル (`$TMPDIR` や `/tmp` 配下のプロセスソケット・ログ・作業ディレクトリ等) を、後片付けとして `rm` で削除しない。

可能であれば、そもそも後片付けが不要な確認手順を優先する (e.g. `mktemp` で作った使い捨てディレクトリをそのまま残す)。

対象はあくまで確認作業のためだけに生成され、後続の作業で参照しない使い捨てのファイル。リポジトリ内の追跡対象ファイルや、意図して残す成果物は対象外。
